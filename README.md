# Frontend — Plataforma Energia Renovável

```bash
npm install
cp .env.example .env   # VITE_USE_MOCK=true roda sem backend
npm run dev
```

Para usar a API real, defina `VITE_USE_MOCK=false` e `VITE_API_URL` (endpoints do Capítulo 5).
Qualquer e-mail/senha entra no modo mock; o perfil escolhido define o menu.
